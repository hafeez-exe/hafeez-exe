## 🔭 Featured Projects

**[LlamaIndex + VL-JEPA Multimodal RAG](https://github.com/hafeez-exe/llamaindex-vljepa-multimodal-rag)**
Architecting a next-generation retrieval pipeline leveraging Meta's V-JEPA for high-fidelity video and image embeddings, backed by Qdrant for scalable nearest-neighbor multi-modal search.

**[Monitoring & Anomaly Detection Lab](https://github.com/hafeez-exe/monitoring-anomaly-lab)**
This project explores automated performance monitoring and anomaly detection for large-scale scientific software pipelines. It implements a rolling statistical baseline (EWMA / rolling mean & std) to detect temporal deviations, alongside regression detection using statistical bounds (Z-score) and machine learning multivariant anomaly detection (Isolation Forest). The repository contains a modular Python structure featuring `data_generator.py` for synthesizing time-series data, `anomaly_detector.py` for composable detection algorithms, and `visualize.py` to map flagged points back onto the metrics timeline.
